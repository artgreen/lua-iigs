# Changelog

## 0.3.0 — 2026-09-25

- Establish a clean source and distribution layout with a fresh Git history.
- Organize examples, upstream tests, IIgs regressions, native hosts, and hardware kits.
- Provide standard and compact distributions, an embedding SDK, and diagnostics.
- Ship thirteen standalone Lua examples, with games, text graphics, algorithms,
  file tools, and coroutine demos; test card rules, results, and input handling.
- Keep the Lua 5.4.6 runtime sources unchanged from the pre-reorganization baseline.
- Preserve identified builds, extracted-byte checks, and ProDOS metadata verification.
- Retain the latest build-isolation, companion-output recovery, and preflight fixes.
- Support building and testing from a source archive without Git metadata.

The port predates this distribution history. Earlier releases were 0.2.1
(minimum-integer conversion fix), 0.2.0, and proof-of-concept releases.
The old development history and exact tested artifacts have been backed up
locally by the maintainer. Release numbering continues from that project.
